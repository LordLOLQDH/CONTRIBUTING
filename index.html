🤝 Contributing Guide

Willkommen im Projekt! Diese Seite erklärt dir detailliert, wie du beitragen kannst, welche Regeln gelten und wie dein Beitrag erfolgreich angenommen wird.

📌 Überblick

Dieses Projekt ist Open Source und lebt von der Community. Jeder Beitrag — egal ob klein oder groß — hilft dabei, das Projekt zu verbessern. Ziel ist es, eine stabile, saubere und erweiterbare Codebasis zu erhalten.

🚀 So kannst du beitragen

Bitte halte dich an den folgenden Ablauf:

  • Forke das Repository auf GitHub
  • Erstelle einen neuen Branch mit einem sinnvollen Namen
  • Implementiere deine Änderungen sauber und dokumentiert
  • Teste deinen Code vor dem Commit
  • Erstelle einen Pull Request mit klarer Beschreibung

Beispiel Branch: feature/user-login

📏 Regeln & Standards

Um die Qualität des Projekts zu sichern, gelten folgende Regeln:

  • Kein unsauberer oder unnötig komplexer Code
  • Klare Struktur und verständliche Variablennamen
  • Keine Breaking Changes ohne Absprache
  • Respektvoller Umgang im Code und in Diskussionen
  • Keine schädlichen oder unsicheren Änderungen

🧪 Code Qualität

Bitte achte darauf, dass dein Code:

  • lesbar und gut strukturiert ist
  • keine unnötigen Wiederholungen enthält
  • kommentiert ist, wenn Logik komplex ist
  • keine Debug- oder Testreste enthält

🔍 Pull Request Guidelines

Ein guter Pull Request enthält:

  • Eine klare Beschreibung der Änderungen
  • Referenz auf ein Issue (falls vorhanden)
  • Screenshots oder Beispiele (wenn relevant)
  • Keine unnötigen Dateien oder Logs

💬 Kommunikation

Bei Fragen oder Problemen kannst du dich jederzeit melden:

📧 auron-team@proton.me

🌟 Warum beitragen?

Beiträge helfen nicht nur dem Projekt, sondern auch dir selbst: Du verbesserst deine Fähigkeiten, lernst echte Entwicklungsprozesse kennen und arbeitest möglicherweise an etwas, das von vielen genutzt wird.

Jeder Beitrag zählt — egal ob Bugfix, Verbesserung oder Idee.
